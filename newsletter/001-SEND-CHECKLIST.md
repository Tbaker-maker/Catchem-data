# Newsletter 001 — Send Checklist (15 min, any calm moment)

1. **Waitlist export:** formspree.io → log in → your form → Submissions →
   Export CSV. Note the COUNT — if >100, Buttondown's free tier is exceeded
   (~$9/mo decision point per COST-LEDGER; make it knowingly).
2. **Buttondown:** buttondown.email → sign up (free) → Settings → basic
   profile (from-name "Catch'Em News", reply-to support@catchemtcg.com).
3. **Import subscribers:** Subscribers → Import → upload the Formspree CSV
   (map the email column). Imported subscribers ≠ emailed yet — safe.
4. **The email:** New Email → switch editor to raw HTML mode → paste the
   ENTIRE contents of newsletter/001-email.html (repo copy is canonical) →
   Subject: exactly `Catch'Em News — One Month to the 30th`
5. **Test send to yourself first** (button in the composer). Check on
   PHONE: masthead renders, dark background holds, links work, no
   [BRACKET] artifacts. Fix nothing by hand in Buttondown — fix in the
   repo file, re-paste. One canonical source.
6. **Send.** Then breathe. Four months.
7. **Post-send (optional, same sitting):** pin the launch-arc Day 6 post
   if the arc is running; save Buttondown's archive link for the arc's
   [link] slots.
