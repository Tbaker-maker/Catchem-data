# Catch'em Intelligence — Set-by-Set Curation List

**Curation rule:** Top 10-15 chase hits from each English Pokemon TCG set.
- Deep sets (Evolving Skies, 151, Brilliant Stars, etc.): 15-20 cards
- Standard sets: 10-15 cards
- Shallow/weak sets: 5-10 cards
- Special/mini-sets (Hidden Fates, Celebrations, etc.): chase highlights only
- **Don't pad with mid cards. If a set has 5 chases, list 5.**

**PLUS — separate rules for Promos and Trainers:**
- **Promos:** ALL promos with TCGPlayer market price > $2
  - Pokemon Center exclusives, event promos, McDonald's tie-ins, etc.
  - Filter applied automatically via pokemontcg.io API
  - You don't need to brain-dump these — the API will catch them
- **Trainers:** ALL trainers with TCGPlayer market price > $5
  - Full Art trainers (Cynthia, Marnie, Iono, etc.)
  - SIR / Special Illustration Rare trainers
  - Filter applied automatically via pokemontcg.io API
  - You don't need to brain-dump these — the API will catch them

**This means your phone brain-dump is JUST the Pokemon chases per set.** The promos and trainers will be auto-filtered when we run the bulk-pull script in Week 1.

**How to use:** Add cards under each set heading as you remember them. Phone-friendly. No research.

**Goal:** ~30-40 sets covered before next PC session = ~300-500 cards listed.
