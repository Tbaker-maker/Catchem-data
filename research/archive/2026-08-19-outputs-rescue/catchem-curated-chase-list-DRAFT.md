# Catch'em Intelligence — Curated Chase List

**Format check version:** Two sample sets done in proposed format. Tyler reviews format, then Claude builds out remaining sets.

**Approach:**
- Top 10-15 chases per set (scaled to set depth)
- Brief why-it's-a-chase notes
- Approximate market price (will be replaced by API actual at build time)
- Key data points (rarity, illustrator if culturally significant, card number)
- Note where API will fill in image URL, exact price, full data

**Confidence flags:**
- ✓ = Verified across 3+ sources
- ⚠️ = Verified once, double-check during build phase
- ⚡ = Recent/volatile, price moved in last 30 days

**Important note on prices:** All prices below are approximate and reflect data from late 2025 to early 2026. The bulk-pull script in Week 1 will replace these with current TCGPlayer market values via pokemontcg.io API.

# 🟥 VINTAGE ERA (1999-2000) — THE FOUNDATION

## Base Set (1999) 🏆

*Released January 9, 1999 | 102 cards | The original Pokemon TCG set | English-language launch*

**Set context:** 🚨 THE ORIGINAL. Released as Pokemon TCG entered English markets. **THREE distinct print variants** — each Base Set card exists in three forms with massively different values:

1. **1st Edition Shadowless** — TRUE ORIGINAL. "Edition 1" stamp + no shadow behind art. Rarest.
2. **Shadowless (Unlimited)** — Second print. No Edition 1 stamp, but still no shadow. "Second-rarest."
3. **Unlimited** — Third print and beyond. Has shadow behind art. Most common.

**This three-tier print structure is unique to Base Set.** Every other vintage set (Jungle, Fossil, Team Rocket, Gym Heroes/Challenge) only has 1st Edition vs Unlimited — the "shadow box" was added permanently starting with Jungle.

1st Edition Charizard PSA 10 = $264,000-$550,000 record sale in 2025-2026. Only 124 PSA 10 1st Edition Charizards exist out of 5,325 graded. Complete 1st Edition PSA 10 set sold for $911,629 in November 2025. THE foundation of all Pokemon TCG collecting.
