# Research Sources

> **Purpose:** Catch'em's institutional memory for external Pokemon TCG research — transcripts, articles, podcasts, competitor material, and third-party data we've learned from.

> **Why this exists:** Ideas and insights from external sources evaporate if not captured. This folder is where we file them so they compound over time. Knowledge accrues.

**Maintained by:** Claude (with Tyler's direction)  
**Started:** 2026-04-22

---

## What goes here

- **YouTube transcripts** from Pokemon TCG content creators (analytical, not hype)
- **Article summaries** from Beckett, PokéBeach, Bulbanews, CardChill, etc.
- **Podcast notes** from relevant episodes
- **Competitor product notes** — what other Pokemon TCG intelligence tools offer
- **Tyler's own research** that he wants Catch'em to remember

## What does NOT go here

- **Paid Patreon content** — if Tyler subscribes to someone's Patreon, that's private research for his own use, not Catch'em content. Do not document paid content in a way that destroys the creator's product.
- **Scraped content** — we respect copyright. Summaries + insights + selected short quotes are fine. Full-text reproductions are not.
- **Personal friends' private takes** — if someone shares info in a DM/private channel, that's between them and Tyler.

## File naming convention

```
YYYY-MM-DD_source-slug_short-description.md
```

Examples:
- `2026-04-22_pika-pika-papa_swsh-monthly-dashboard.md`
- `2026-05-01_cardchill_prismatic-evolutions-market-analysis.md`
- `2026-06-15_pokebeach_chaos-rising-set-list-announcement.md`

## Required sections in each file

Every research note should include:

1. **Metadata header** — source, date, URL, creator, medium
2. **Executive summary** — 3-5 sentences on what this source says
3. **Key insights** — bulleted list of takeaways
4. **Verbatim quotes worth preserving** — short, attributed, used sparingly
5. **Implications for Catch'em** — what we might build, borrow, differentiate, avoid
6. **Counter-observations** — where we disagree or see gaps
7. **Filed date** — when this note was created

## How to use this folder

### Weekly rhythm
- When Tyler or Claude encounters a new authoritative source → create a new note
- At session start, if the topic relates to existing research → grep this folder first
- Once a quarter → review notes and update the competitor-intelligence doc

### When writing a Catch'em Signals newsletter
- Check this folder for relevant insights that might inform the issue
- Quote sparingly and attribute properly
- Never regurgitate — always add Catch'em-original analysis on top

### When designing a new app feature
- Check if a research source has already thought about this
- Learn from their approach, differentiate in execution
