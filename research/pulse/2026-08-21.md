## 💡 Did you know?
**Base Set is the only main English expansion with no set symbol.** Every other English main-series set stamps a symbol beside the artwork. Base Set doesn't — so the fastest identification test is the absence of one, plus a card number out of 102.

*It's the quickest way to spot a 1999 Base card in a bulk pile without knowing a single card name.* — Bulbapedia: Base Set (TCG); Big Orbit Cards: Base Set identification guide, checked 2026-08-21.
